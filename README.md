# 白云阁

**https://nicholas2015.github.io**

一个后端工程师的技术笔记。2014 年写到现在，记的都是真实项目里踩过的坑。

## 这里有什么

三类内容，都从具体问题出发：

- **中间件怎么搭、怎么查** — Kafka 集群与消费积压、Elasticsearch 集群与深分页、Redis、MySQL、Docker/K8s
- **线上问题怎么定位** — JVM GC 毛刺、网关超时重试失效、JDK 升级后的内存变化
- **AI 怎么真正落进 Java 工程** — Spring AI、LangChain4j、MCP Server、RAG 检索与 Embedding 选型、多智能体分工、本地模型部署

## 你能得到什么

- **能直接照着做的步骤**：命令和配置可以原样复制，不是概念科普
- **完整的排查过程**：从现象、报错，到怎么一层层缩小范围，最后结论是什么
- **别人踩过的弯路**：哪条路走不通、为什么走不通，省下自己试错的时间

## 适合谁

- 正在搜某个具体报错或配置写法，想尽快把问题解决的后端开发
- 想把 AI 能力接进现有 Java 系统，但不确定从哪下手的工程师
- 想看看别人线上问题是怎么查的同行

## 顺带还有

- **在线小工具**：Base64、JSON 格式化、JWT 解析、密码生成、YAML / properties 互转，都在浏览器本地算，不上传
- **自己写的桌面小工具**：介绍、截图和下载入口
